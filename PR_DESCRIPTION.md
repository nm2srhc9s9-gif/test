# Входящие заявки: валидация ввода, таймаут AI и ручной разбор

## Запуск и тесты
```sh
node server.mjs        # http://127.0.0.1:3000, порт — через PORT
npm test               # или: node --test test/triage.test.mjs
```
Нужен Node.js 20+, зависимостей нет.

## Где проверяется результат AI
В одном месте — `parseModelOutput()` в `server.mjs`: ответ должен быть JSON-объектом, `topic` — одна из `delivery` / `pricing` / `other`, `draft` — непустая строка (после trim). Всё остальное — `manual_review`. Страница дополнительно не показывает черновик, если он пустой.

## Что происходит при сбое
- Пустой, отсутствующий, нестроковый `text` или битый JSON → HTTP 400 `{"status":"invalid_input"}`; на странице — «Введите текст заявки» (пустой ввод ловится и до запроса).
- Таймаут (300 мс), исключение модели, не-JSON, чужая тема, пустой черновик → HTTP 200 `{"status":"manual_review","topic":null,"draft":null}`. Модель отменяется через `AbortSignal`; если провайдер сигнал игнорирует, `Promise.race` всё равно отдаёт ответ по лимиту.
- Страница перед каждым запросом очищает прошлый черновик и тему; при `manual_review` или сетевой ошибке показывает сообщение «разберите заявку вручную». Кнопка блокируется на время запроса.
- `mock-ai.mjs` не менялся.

## Какой AI использовался
Claude (Claude Code, модель Claude Opus 5.5) — для написания кода, тестов и этого описания.

## Что проверено самостоятельно
- `npm test`: 16/16 — успех, 8 видов некорректного ввода, `[error]`, `[bad-json]`, `[bad-topic]`, `[empty-draft]`, `[timeout]` (ответ ≈305 мс), провайдер, игнорирующий `AbortSignal`, и юнит-проверка `parseModelOutput`.
- Вручную в браузере: «Когда будет доставка?» → тема «Доставка» и черновик; затем «Доставка [timeout]» → черновик исчез, показано сообщение о ручном разборе.

## Польза для менеджера
Менеджер получает тему и заготовку ответа за доли секунды и никогда не видит устаревший или битый черновик — при сбое сразу ясно, что заявку нужно разобрать вручную; измерять можно медианным временем от поступления заявки до ответа клиенту и долей черновиков, отправленных без существенных правок (плюс доля `manual_review`).

## Не сделано
Тест страницы в браузере не автоматизирован (проверено вручную).
